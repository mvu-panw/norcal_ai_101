The Basics

AI, machine learning, deep learning, generative AI and agentic AI, and where Claude Code fits.

How the terms fit together

Artificial Intelligence 1950s →
Any technique that lets computers do things that normally need human intelligence.
Machine Learning 1980s →
AI that learns patterns from data instead of following hand-written rules.
Deep Learning ~2010 →
Machine learning with deep neural networks that discover their own features.
Generative AI 2017 →
Deep learning models, such as large language models (LLMs), that create new content.
Where's agentic AI? It isn't another ring. Agentic AI is a system built around a generative model: the model does the thinking, and the system around it adds goals, tools, memory and a loop so it can take actions. Claude Code is one of these systems.

Quick definitions

Artificial intelligence (AI)

The broad goal of making computers do things that normally take human intelligence: recognizing images, understanding language, making decisions. Early AI (1950s onward) was mostly hand-written rules and game playing, like checkers.

Machine learning (ML)

Instead of writing rules, you show the computer examples and it learns the pattern with statistics. The catch: people still decide which features matter. A classic example is the email spam filter, which learned from word counts that a human chose to track.

Deep learning (DL)

Machine learning with deep neural networks: many layers of simple artificial "neurons." The big difference is that the network learns its own features from raw data, with no human-designed feature extractors. It took off around 2010 thanks to GPUs, big datasets and better algorithms. In 2012, AlexNet won the ImageNet challenge after training on GPUs.

Generative AI

Deep learning models that create new content: text, code, images, audio. Large language models are built on the transformer (2017), pre-trained on huge amounts of unlabeled text, and work by predicting the next token, one at a time. When Claude writes the HTML for our demo site, that's generative AI.

Agentic AI

AI that doesn't just answer but gets a job done: it breaks a goal into a plan, uses tools (search, code, files, databases), checks the results, and keeps going until the task is finished. It has guardrails, and a human approves the risky steps.

ML vs. DL in one line

Machine learning: humans choose the features, and the model learns the weights.
Deep learning: the model learns the features and the weights, but it needs far more data and compute. That's why GPUs matter.

How a neural network learns

  1. Guess. Feed in a labeled example, like a photo marked "cat." The network outputs a guess with a confidence score.
  2. Compare. Check the guess against the label.
  3. Adjust. Strengthen the connections (weights) that led to a right answer and weaken the ones that led to a wrong one.
  4. Repeat. After one pass through the data it's barely better than a coin flip. Many passes later, it's accurate.

So what is Claude Code?

Both generative and agentic. Generative AI writes the answer. Agentic AI does the job. Claude Code is a generative model running inside an agent.

The model: generative AI

  • Claude, running in a data center
  • Reads the prompt and writes tokens: text, code, or a request to use a tool
  • Never touches your laptop or your files

Claude Code: the agent

  • Runs on your laptop
  • Gives the model a goal and a set of tools, then runs them when asked
  • Feeds the results back and loops until the job is done
