What Happens When You Hit Enter?

The 30-second version

  • Claude Code is both generative and agentic. A generative model (Claude) writes the code, and an agent loop on your laptop plans, uses tools and checks results. The Basics →
  • The app is local, the model is remote. An AI coding agent like Claude Code runs on your laptop. The model that does the thinking runs on GPU or accelerator clusters in a data center.
  • Everything travels as text over HTTPS. Your prompt, the agent's instructions, and the file contents it has read are packaged into one encrypted request. The answer streams back a few tokens at a time.
  • The model doesn't touch your files. It sends back requests like "write index.html with this content." Your laptop runs them and reports the result. A simple task can take several of these round trips.
  • In the data center, one model spans a whole rack. A frontier model is too big for one GPU. Systems like the NVIDIA GB300 NVL72 connect 72 GPUs with NVLink so they behave like one giant accelerator.
  • Two phases, two bottlenecks. Prefill reads your whole prompt at once and is limited by compute. Decode writes the answer one token at a time and is limited by memory bandwidth.

The demo prompt

We open with this prompt, typed live into Claude Code:

"Add a dark mode toggle to this page."

Watch for three things:

  • The reply streams in rather than arriving all at once.
  • Claude Code asks permission before changing each file.
  • /context shows how many tokens travel with every request.

The site you're reading was built the same way.

AI basics in four terms

Token
A chunk of text, often part of a word. Models read and write tokens, not characters.
Parameters
The learned numbers inside a model. Frontier models have hundreds of billions or more.
Training
Months on thousands of GPUs to learn the parameters. Done once per model.
Inference
Using the trained model to answer a prompt. Happens billions of times. This talk is about inference.
